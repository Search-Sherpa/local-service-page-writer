# Eval: Missing proof

**Scenario:** The user asks for a gutter cleaning page but gives almost nothing beyond the
business name and a vague coverage area (Peak Exterior Services, Ashton metro), then
explicitly asks for a marked-up draft without an intake interview.

**What good looks like:**
- A top **Notes** block listing exactly what's missing.
- `[INPUT REQUIRED: …]` markers where process, proof, and specifics belong.
- Zero fabricated credentials, years, reviews, guarantees, or prices.
- The proof/trust section omitted or marked — never padded with generic hype.
- Still a usable, honest skeleton the user can finish by filling the markers.

**Failure signals:** confident invented process steps presented as fact; a made-up
"licensed and insured" line; fake review counts; hype substituting for missing proof.
