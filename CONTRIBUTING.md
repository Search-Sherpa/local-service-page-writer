# Contributing

Thanks for helping improve Local Service Page Writer.

This is a public repository, but only the repository owner and explicitly approved
collaborators can change the upstream project. Everyone else should propose changes in
one of these ways:

1. Open an issue describing the problem, use case, or requested improvement.
2. Fork the repository and open a pull request with a focused change.

No outside contribution becomes part of the project unless the maintainer reviews and
merges it. Please do not include private client data, credentials, real customer details,
or unverifiable marketing claims in examples or evals.

For changes to writing behavior, include or update an eval that demonstrates the intended
result. Keep examples fictional and preserve the skill's honesty, location, and
produce-only guardrails.
